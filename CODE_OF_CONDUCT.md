# Code of conduct

This project welcomes everyone: students, researchers and professionals, beginners and experts, in any language.

- Be respectful and patient, especially with people who are new to GIS or to programming.
- Criticise ideas and results, never people.
- Assume good faith, and ask before concluding.
- No harassment, insults or discrimination of any kind.

Problems can be reported privately to the maintainer through the contact options on [his GitHub profile](https://github.com/abdelaalimouid). Reports are handled confidentially.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
